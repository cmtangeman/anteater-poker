## Installation Instructions

For the source package:
1. Extract the archive:
   tar -xvzf Poker_Beta_src.tar.gz
2. Enter the project directory:
   cd Poker_Beta_src.tar
3. Build the program:
   make
4. Run the Program:
No GUI Interface:                             GUI Interface:
1. Client: ./bin/poker localhost (PORT)       1. Client: ./bin/poker_client localhost (PORT)
2. Server: ./bin/server (PORT)                2. Server: ./bin/poker_server (PORT)

For more details, refer to the user manual and software specification in the doc directory.
