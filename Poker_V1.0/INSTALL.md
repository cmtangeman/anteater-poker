## Installation Instructions

For the binary package:
1. Extract the archive:
   tar -xvzf Poker_V1.0.tar.gz
2. Enter the project directory:
   cd Poker_V1.0
3. Run the executable of your choice:
   client: ./bin/poker_client localhost (PORT)    server: ./server (PORT)

For more details, refer to the README, or user manual in the doc directory.
