This game is an adaptation of Texas Hold'em Poker, with additional features in the theme of the mascot of UCI the Anteater.
To learn more about the installation process, please see the intall file.

Before running the game, you will need one of the ports in the UCI EECS servers.
Make sure all users are using the same server (e.g. bondi)

## To run the game:

    Server: ./bin/server (PORT) <----- replace port with port number

    Client: ./bin/poker_client localhost (PORT) <----- replace port with port number
(MAKE SURE TO LAUNCH SERVER FIRST)

For more information, refer to the User Manual document.
We hope you enjoy our game!
