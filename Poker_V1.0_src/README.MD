This game is an adaptation of Texas Hold'em Poker, with additional features in the theme of the mascot of UCI the Anteater.
To learn more about the installation process, please refer to the install file.

## To run the program you have a few options:

No GUI Interface:                             GUI Interface:
1. Client: ./bin/poker localhost (PORT)       1. Client: ./bin/poker_client localhost (PORT)
2. Server: ./bin/server (PORT)                2. Server: ./bin/poker_server (PORT)
(MAKE SURE TO LAUNCH SERVER FIRST)

Please run the terminal server.
For testing, please refer to the testing.md file.
To compress the source files, please use ----> make tar
For more information, refer to the User Manual and Software Specification documents.

We hope you enjoy our game!
